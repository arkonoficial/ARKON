# ARKON

**Plataforma educativa interactiva** sobre prevención de riesgos, convivencia, ciudadanía y habilidades para la vida laboral.

## Ver el proyecto

- **Código principal:** [index.html](./index.html)
- **Repositorio:** https://github.com/juanesquejadajaramillo-arch/ARKON

## Qué incluye

- Guías educativas sobre prevención de riesgos y fenómenos naturales.
- Módulos interactivos de habilidades laborales.
- Biblioteca con buscador y filtros.
- Preguntas de práctica con retroalimentación.
- Listas de comprobación y progreso guardado en el navegador.
- Recursos y fuentes institucionales.
- Secciones del proyecto ABP, estadísticas editables y créditos.

La plataforma es un sitio estático: no requiere instalar librerías ni configurar un servidor para probar el archivo localmente.

## Publicar la web con GitHub Pages

1. Entra al repositorio y abre **Settings**.
2. En el menú lateral, entra a **Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)`.
5. Pulsa **Save**. Después, en esa misma pantalla, usa **Visit site** para abrir la web publicada.

La página publicada será pública. GitHub puede tardar varios minutos en desplegar los cambios.

## Notas

- Los avances se guardan localmente en el navegador; no se sincronizan entre dispositivos.
- Las estadísticas de ejemplo del proyecto empiezan en cero. Introduce únicamente datos agregados y reales de tu encuesta.
- El contenido de prevención es educativo y no sustituye las alertas, protocolos ni instrucciones de las autoridades.
